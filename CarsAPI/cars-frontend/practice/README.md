# Preserved React exercises

These examples are retained from earlier lessons. They remain TypeScript-checked, but production routes do not import them. Revisit an example by intentionally importing it into a client component or practice route.

| Topic | Files |
| --- | --- |
| Components, props, callbacks | `components/PracticeCar.tsx`, `components/CarAvailability.tsx` |
| State and controlled inputs | `components/CarPrice.tsx`, `components/CarForm.tsx` |
| Conditional rendering and render props | `components/AvailabilityMessage.tsx` |
| Effects and fetching | `components/CarFetchDemo.tsx`, `components/HorsepowerTracker.tsx` |
| DOM refs | `components/CarSearch.tsx` |
| Functional/class components | `components/CarBanner.tsx`, `components/CarPhoto.tsx` |
| Context | `context/UsernameContext.tsx`, `components/UsernameEditor.tsx`, `components/UserProfile.tsx` |
| Custom hooks | `hooks/useCounter.ts`, `hooks/useOnlineStatus.ts`, `components/ConnectionStatus.tsx` |
| Earlier card | `components/LegacyCarCard.tsx` |

`PracticeCar.tsx` was `app/file.tsx`; `CarPrice.tsx` was `app/file - Copy.tsx`. The earlier card is named `LegacyCarCard` to distinguish it from the active dashboard card.

Some exercises intentionally retain earlier patterns, English-only labels, or a local API URL. They are learning examples rather than production replacements.

See the [current folder guide](../docs/project-structure.md).
